# cuebracket

## Phase 4M · Club identity and guided onboarding

- Club owners and admins can publish the venue location, opening hours and joining rules. A player must accept the current guide version before requesting membership.
- Clubs, player profiles, tournaments and club achievements support optional JPG, PNG or WebP images up to 5 MB with owner-scoped storage policies.
- Club achievements can include photos, player cards show public follower totals, and public players remain one tap away from Follow and match alerts.
- Club logos, player photos and tournament posters carry through the directory, dashboards, club pages and public tournament surfaces.
